# Projeto Cassino C# .Net (Jogo de Console) - Kevyner Venzke Ramalho

## Resumo
É um jogo de azar onde o usuário ganha um saldo de 100R$ e pode usá-lo para apostar na loteria ou raspadinhas.

## Funcionalidades
O menu principal tem 3 opções jogar na loteria, jogar na raspadinha (tem dois tipos), e ele tem a liberdade de sacar ou depositar a quantia que quiser
